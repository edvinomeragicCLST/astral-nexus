# Okvirni prijedlog UI-a

Tok aplikacije: Splash -> Welcome/Carousel -> Login/Register -> Dashboard. Sa Dashboarda korisnik otvara Kolekciju, Moje špilove, Pakete, Simulator meča, Historiju, Profil i Postavke.

Principi: veliki touch targeti, dvije karte u redu na kolekciji, vertikalna navigacija, jasan status coina i broja karata, svijetla/tamna tema.
